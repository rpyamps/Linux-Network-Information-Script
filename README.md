# Linux-Network-Information-Script

## Description
This Repository contains Python and Bash scripts created to collect system information and network information from Ubuntu and CentOS servers.
The scripts display the information in the terminal and saves the result to a text file.

## Scripts
The Ubuntu_script.py collects system and network information from the Ubuntu Server.
The CentOS_script.py collects system and network information from the CentOS server. 
The network_troubleshooting.sh script displays troubleshooting commands for Ubuntu and CentOS.


## How to run the scripts
For Ubuntu run command ./Ubuntu_script.py or python3 Ubuntu_script.py
For CentOS run command python3 CentOS_script.py
For the troubleshooting script run command bash network_troubleshooting.sh

## Output from the scripts
The scripts will display the network information in the terminal ans save the information to a text file in the Network Reports Folder.
The date will get automatically added to the report filename.
The network_trobleshooting.sh script displays troubleshooting commands based on whether the user selects Ubuntu or CentOS. 

## Requirements to run it
Have Python3 install,and an Ubuntu or CentOS Linux server.
Bash is required to run the network troubleshooting script.
